Использование системы сборки PHP
=================================

В этой главе мы объясним, как использовать систему сборки PHP для компиляции как самого PHP, так и дополнительных
расширений. В этой главе пока не рассматривается написание собственных инструкций сборки на autoconf — объясняется
только то, как использовать инструменты сборки.
