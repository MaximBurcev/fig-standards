Введение¶

Эта книга — результат совместной работы нескольких разработчиков языка PHP, цель которой — лучше документировать и описать, как PHP устроен внутри.

У книги три основные цели:

  • Документировать и описывать, как устроены внутренности PHP.

  • Документировать и описывать, как расширять язык с помощью расширений.

  • Документировать и описывать, как вы можете взаимодействовать с сообществом, чтобы участвовать в разработке самого PHP.

Эта книга в первую очередь рассчитана на разработчиков, имеющих опыт работы с языком C. Однако там, где это возможно, мы постараемся упростить и обобщить информацию, чтобы разработчики, не очень хорошо знающие C, тоже могли понять материал.

Тем не менее позвольте настоять: вы не сможете добиться чего-то продуктивного, стабильного (без падений на любой платформе), производительного и полезного, если не знаете язык C. Вот несколько неплохих онлайн-ресурсов о самом языке C, его экосистеме и инструментах сборки, а также об API операционных систем:

  • http://www.tenouk.com/

  • https://en.wikibooks.org/wiki/C_Programming

  • http://c-faq.com/

  • https://www.gnu.org/software/libc/

  • http://www.faqs.org/docs/Linux-HOWTO/Program-Library-HOWTO.html

Мы также настоятельно рекомендуем несколько книг. С их помощью вы научитесь эффективно использовать язык C и переводить его в эффективные инструкции CPU, чтобы создавать мощные/быстрые/надёжные и безопасные программы.

  • The C Programming Language (Ritchie & Kernighan)

  • Advanced Topics in C Core Concepts in Data Structures

  • Learn C the Hard Way

  • The Art of Debugging with GDB DDD and Eclipse

  • The Linux Programming Interface

  • Advanced Linux Programming

  • Hackers Delight

  • Write Great Code (2 Volumes)

Note

Эта книга находится в процессе написания (Work-In-Progress), и некоторые главы ещё не написаны. Мы не придерживаемся строгого порядка, а добавляем материал по мере готовности.
